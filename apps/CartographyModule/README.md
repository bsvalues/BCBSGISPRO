# CartographyModule

This module contains all mapping, cartography, and map export functionality for the TerraFusion platform.

## Features

- Interactive map rendering with multiple providers (Mapbox, ArcGIS)
- Advanced drawing and annotation tools
- Layer management and styling
- Map printing and PDF export
- Measurement tools

## Usage

The CartographyModule is used throughout the application for displaying and interacting with spatial data. It provides components that can be embedded in various workflows.

## Key Components

- MapProviderSelector: Allows switching between different map providers
- CartographerMap: Core map component with drawing capabilities
- PrintMap: Map export and printing functionality
- LayerManager: Handles map layer visibility and styling

## Integration

This module integrates with the ETL module for data sources and with the WorkflowUI for embedding maps in workflows.
