## **2. API Client Implementation Example**

Create `/libs/services/counties.ts`:

```typescript
// libs/services/counties.ts
import { County } from '../types/County';

export async function getCounties(): Promise<County[]> {
  const res = await fetch('/api/counties');
  return res.json();
}

export async function getCounty(id: string): Promise<County> {
  const res = await fetch(`/api/counties/${id}`);
  return res.json();
}
```

**Repeat for parcels, valuations, etc.**
