## **1. User Profile Management**

**Goal:**
Give every user (and admin) an account page for profile review, password/MFA management, and—if admin—role assignment.

**Tasks:**

* Profile Page (e.g., `/profile`):

  * Show: Name, email, auth provider, current role, last login
  * Buttons: “Change Password” (if local), “Add MFA” (optional), “Edit” (admin only)
* Admin: List all users, edit roles
* Route: Protected (only logged-in can access)

**Sample Profile Page UI (React/TSX):**

```tsx
export function ProfilePage({ user }) {
  return (
    <div className="max-w-md mx-auto bg-white rounded-xl shadow p-6">
      <h1 className="text-xl font-bold mb-4">User Profile</h1>
      <div>Name: {user.name}</div>
      <div>Email: {user.email}</div>
      <div>Role: {user.role}</div>
      <div>Provider: {user.provider}</div>
      <div>Last Login: {user.lastLogin}</div>
      {/* Add change password/MFA buttons */}
      {user.isAdmin && (
        <a href="/admin/users" className="mt-4 block text-blue-500">Manage Users</a>
      )}
    </div>
  );
}
```

## **3. Audit Logging**

**Goal:**
Track security-sensitive actions for compliance and future troubleshooting.

**Tasks:**

* Log every login attempt (success/failure, user, IP, provider)
* Log password resets, MFA changes
* Log role assignments, user creation, deactivation
* Log key workflow actions (document upload, workflow creation, approval)
* Store logs in a secure DB table (e.g., `audit_log`)
* (Optional) Add an admin “Audit Log” page

**Sample Audit Log Table (SQL):**

```sql
CREATE TABLE audit_log (
  id SERIAL PRIMARY KEY,
  user_id UUID,
  action VARCHAR(50),
  detail JSONB,
  ip_address VARCHAR(45),
  timestamp TIMESTAMPTZ DEFAULT now()
);
```

**Logging Example (Node/Express):**

```js
await db.audit_log.create({
  user_id: user.id,
  action: "login_success",
  detail: { provider: "google" },
  ip_address: req.ip
});
```

## **4. Granular RBAC Expansion**

**Goal:**
Add more roles and fine-grained permission controls.

**Sample Roles:**

* **admin:** Full control
* **staff:** Standard access (create/edit workflows, docs)
* **field:** Field tools only (view parcels, create field notes)
* **readonly/public:** View only, no editing

**Sample RBAC Context (React):**

```tsx
export const RBACContext = createContext({ role: "readonly", canEdit: false, canApprove: false });
```

In your route/component logic:

```tsx
{rbac.role === "admin" && <AdminPanel />}
{rbac.canEdit && <EditButton />}
```

## **5. API Endpoints for User Management & Security**

**Tasks:**

* `POST /api/users` (admin only): create user
* `PATCH /api/users/:id` (admin): update user/role
* `GET /api/users` (admin): list users
* `GET /api/audit-log` (admin): view logs

**Sample API Response:**

```json
[
  { "id": "u1", "email": "bob@county.gov", "role": "admin", "lastLogin": "2025-05-22T15:22:01Z" }
]
```

## **7. Security & Best Practices Checklist**

* All JWT tokens securely signed and stored (httpOnly cookie or secure storage)
* All passwords hashed (bcrypt or Argon2)
* Role checks on all protected API endpoints (backend and frontend)
* Audit logs protected from tampering
* Database backups and access controls in place
