## 🟢 **Code Example: “Live Only” Map Panel**

```tsx
// Example React component — loads real parcels or shows “No Data” if not available
import { useEffect, useState } from "react";
import { fetchParcelsFromBackend } from "../api"; // <-- Your real data API

export function RealParcelMap() {
  const [parcels, setParcels] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetchParcelsFromBackend()
      .then(data => setParcels(data))
      .catch(() => setParcels([]))
      .finally(() => setLoading(false));
  }, []);

  if (loading) return <div>Loading parcels...</div>;
  if (!parcels.length) return <div>No parcels available.</div>;

  return (
    <div>
      {/* Render your real parcels here */}
      {parcels.map(parcel => (
        <div key={parcel.id}>{parcel.name}</div>
      ))}
    </div>
  );
}
```

* **No fallback to “dummy” data, ever.**
* If backend returns nothing, show empty or “No Data”—**never** a fake list.
