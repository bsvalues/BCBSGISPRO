🟢 3. AI Audit Summary Code Template (Node/TS or Python)
Prompt for LLM (OpenAI, Gemini, etc.):

text
Copy
Edit
Summarize the recent events for Parcel #10003 in plain English. Highlight any anomalies, access denied attempts, or unusual activity. If all actions are typical, state “No anomalies detected.”
Node/TS Example:

js
Copy
Edit
const auditEvents = [
  {action: "workflow_start", user: "staff@bentoncounty.gov", time: "10:05", details: {}},
  {action: "doc_upload", user: "staff@bentoncounty.gov", time: "10:10", details: {type: "deed"}},
  {action: "access_denied", user: "readonly@bentoncounty.gov", time: "10:12", details: {}},
];

const prompt = `
Summarize the following activity for parcel 10003:
- 10:05: Workflow started by staff@bentoncounty.gov
- 10:10: Deed document uploaded by staff@bentoncounty.gov
- 10:12: Access denied for readonly@bentoncounty.gov

Plain English summary, highlight any issues.
`;

const aiSummary = await openai.complete({ prompt, max_tokens: 100 });
console.log(aiSummary.text);
// Output: "All actions appear normal for parcel 10003, except for an access attempt by a readonly user which was properly denied. No anomalies detected."
