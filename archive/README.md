# TerraFusion Archive

This folder contains legacy code, unused components, and reference materials that have been moved out of the active codebase.

## Contents
- `/legacy-tests/` - Old test files that are no longer relevant
- `/unused-scripts/` - Scripts and utilities not currently in use
- `/reference-docs/` - Documentation and assets for reference only
- `/deprecated-modules/` - Old modules and components superseded by newer implementations
